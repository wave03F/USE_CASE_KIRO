🍅 โจทย์ของเรา: Pomodoro Timer คืออะไร?

เทคนิค Pomodoro คือการโฟกัสงาน 25 นาที แล้วพัก 5 นาที สลับกันไป เว็บที่เราจะสร้างมีปุ่ม Start / Pause / Reset, นับถอยหลังบนหน้าจอ, สลับโหมดโฟกัส/พักอัตโนมัติ และมีเสียงเตือนเมื่อหมดเวลา โจทย์เล็กแต่ครบองค์ประกอบของเว็บแอปจริง

ก่อนเริ่ม

เตรียมตัว 3 อย่าง

  1. ติดตั้ง Kiro — เปิด Kiro IDE ขึ้นมาให้พร้อม (ถ้ายังไม่มี ดูวิธีสมัครฟรีที่หน้าหลัก)
  2. สร้างโฟลเดอร์ว่าง — เช่น pomodoro-lab แล้วเปิดเป็น workspace ใน Kiro
  3. เปิด Chat ของ Kiro — เราจะพิมพ์คุยกับ Kiro ทั้งหมดจากตรงนี้ ไม่ต้องเปิดไฟล์เขียนเอง
เคล็ดลับ แต่ละขั้นตอนมีปุ่ม คัดลอก prompt ให้กดแล้ววางใน Chat ของ Kiro ได้เลย ปรับแก้คำได้ตามใจ
ลงมือทำ
